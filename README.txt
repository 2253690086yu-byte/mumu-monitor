MuMu 模拟器内存监控 - 便携版
================================

【使用方法】
1. 先启动 MuMu 模拟器(要监控哪个实例就开哪个,支持多开)
2. 双击「启动监控.bat」,浏览器会自动打开监控页面
3. 不用了直接关掉黑色命令行窗口即可

【功能】
- 每 1 秒刷新:已用/可用内存、缓存、Swap、内存使用率
- 已用内存 3 分钟趋势图(鼠标悬停看具体数值)
- 进程内存排行(PSS 前 10)
- MuMu 多开实例自动发现:新开一个模拟器窗口,约 5 秒后自动出现新标签页
- 支持浅色/深色主题(右上角按钮)

【常见问题】
Q: 页面显示"无实例在线"?
A: 确认 MuMu 模拟器已经启动并完全进入系统。每个实例的 adb 端口规则:
   实例 0 = 16384,实例 1 = 16416,实例 2 = 16448(步长 32)。
   如果你手动改过 MuMu 的 adb 端口,请用命令行启动并指定端口:
   runtime\node.exe server.js PORTS=16384,21503

Q: 双击后浏览器没打开?
A: 手动访问 http://127.0.0.1:8765(若被占用会自动换 8766-8775,
   以命令行窗口显示的地址为准)。

Q: 会被杀毒软件报毒吗?
A: 不会。运行时是 Node.js 官方原版 node.exe,adb 是 Google 官方
   platform-tools,均为未修改的官方文件。

【文件说明】
启动监控.bat   启动入口
server.js      后端服务(adb 采集 + 本地网页服务)
index.html     监控页面
runtime/       Node.js 运行时(免安装)
adb/           adb 工具(优先使用 MuMu 自带的 adb,此目录为兜底)

【隐私说明】
本工具只在你的电脑本机(127.0.0.1)通信,不联网、不上传任何数据。
